# 模板文件

当前目录已经根据用户提供的手机截图裁剪按钮，尺寸按 MuMu 当前 1920×1080 界面中的实际按钮尺寸保留：

- `purchase_button.png`：裁剪购买按钮的稳定区域，最好包含按钮文字和边框。
- `stacked_purchase_button.png`：叠挂弹窗中的第二次“购买”按钮。
- `confirm_order_button.png`：确认弹窗右侧的“确定”按钮。

`recovery/` 保存游戏异常退出后的恢复流程模板：MuMu 桌面游戏图标、服务器角色“哇卟叽叽”、角色开始、商业街、店铺和我的关注。两个登录动画步骤均不使用模板：“点击选服”在首次固定等待结束后点击配置坐标，选择服务器角色后再等待 10 秒并直接点击模拟器中心。其余模板由用户提供的 MuMu 1920×1080 原始画面裁剪；页面布局变化后可使用 `tools/build_recovery_templates.py` 重新生成并校准 `config.json` 中的搜索区域。

公示期状态不再使用文字模板：倒计时数字不断变化，脚本改为在目标商品卡片右下区域检测红色像素是否消失。

推荐流程：

1. 先运行 `python main.py --capture work/full_screen.png` 抓取当前屏幕。
2. 用任意图像工具重新裁剪购买和右侧确定按钮模板，保存到本目录。
3. 在上级 `config.json` 中填写按钮的 `region`，并重新校准 `status_detection` 中的选中框和红字 ROI。
4. 先保持 `runtime.dry_run=true` 验证识别和坐标；确认无误后，且仅在获授权的测试环境中，才考虑改为 `false`。

模板匹配不具备 OCR 的语义理解能力：按钮颜色、字体、缩放或主题变化都会影响分数。页面改版后应重新制作模板并重新校准阈值。
